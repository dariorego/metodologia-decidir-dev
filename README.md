# Metodologia DECIDIR - desenvolvimento

Material da imersão **Da ideação à aplicação publicada**, módulo prático do Método DECIDIR.

Doze passos entre uma dor real e uma aplicação publicada, sem escrever código à mão: os sete pilares do DECIDIR aplicados a construir software, PRD, SDD, ideação visual com o Claude, Claude Code na IDE, estrutura de pastas, banco no Supabase, prompt de construção, GitHub, empacotamento em Docker e o acesso ao projeto no ar.

**Stack da sala:** Next.js (App Router e TypeScript), Supabase, Docker e Traefik.
