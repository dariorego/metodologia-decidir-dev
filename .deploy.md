# Deploy — Ponto Residentes

Stack: Next.js (standalone) em Docker, publicado atrás do Traefik com TLS automático.

## Pré-requisitos no servidor

- Docker + Docker Compose.
- Traefik rodando com a rede externa `traefik`, entrypoint `websecure` (443) e certresolver `letsencrypt`.
- DNS do domínio apontando para o servidor.

## Passos

```bash
git clone <repo> && cd metodologia-decidir-dev

cat > .env <<EOF
PONTO_DOMAIN=ponto.exemplo.org.br
NEXT_PUBLIC_SUPABASE_URL=https://uwwcrulhfrleqlmgmbcm.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon key>
EOF

docker compose up -d --build
docker compose logs -f ponto-web
```

O `docker-compose.yml` na raiz constrói `apps/web/Dockerfile` (multi-stage, imagem final ~150 MB,
usuário sem privilégio) e registra as labels do Traefik.

## Supabase

1. Executar `supabase/migrations/0001_ponto_schema.sql` no SQL Editor (uma vez; idempotente).
2. Em **Authentication → URL Configuration**, adicionar `https://<PONTO_DOMAIN>` em *Site URL / Redirect URLs*.
3. Opcional: `npm run seed:demo` em `apps/web` com a chave `service_role` para criar contas de demonstração.

## Atualizar

```bash
git pull && docker compose up -d --build
```

## Rollback

```bash
git checkout <commit-anterior> && docker compose up -d --build
```
